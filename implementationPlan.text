# Integrate Bhasa (Language Service) into Voice Agents Main Project

## Project Analysis Summary

Your **Voice Agents** workspace contains **three codebases**:

| Codebase | Location | Stack | Status |
|----------|----------|-------|--------|
| **Main Project** (root) | `d:\Voice Agents\` | Node.js/Express, 7 microservices on ports 4001–4007 | ✅ Working MVP with mock STT/NLU/TTS |
| **Bhasa** | `d:\Voice Agents\bhasa\` | Python/FastAPI, single service on port 8003 | ✅ Real AI: Whisper ASR + Ollama NLU + gTTS/Coqui TTS |
| **voice-ai-saas** (v2) | `d:\Voice Agents\voice-ai-saas\voice-ai-saas\` | Node.js, 9 services, Docker-native, Dockerfiles | 🔨 Scaffolded but has port conflicts & incomplete wiring |

### The Core Problem

The **main project's** `stt-service`, `nlu-service`, and `tts-service` are **mock stubs** — they return static/rule-based responses. Meanwhile, **Bhasa** has **real AI capabilities** (Whisper, Ollama/OpenAI, gTTS/Coqui/ElevenLabs) but is a standalone Python service that nobody calls.

### Integration Goal

Wire the main project's three mock Node.js services to call Bhasa's real AI endpoints when `MOCK_MODE=false`, giving you **real speech-to-text, AI-powered NLU, and multilingual TTS** without rewriting the Node.js architecture.

---

## User Review Required

> [!IMPORTANT]
> **Bhasa becomes a required dependency.** When `MOCK_MODE=false`, the three Node.js services will HTTP-proxy to Bhasa at `LANGUAGE_SERVICE_URL` (default `http://localhost:8003`). If Bhasa is down, the services will return 503 errors.

> [!IMPORTANT]
> **Bhasa runs as a separate Python process.** You'll need Python 3.10+ and `pip install` for Bhasa's dependencies, plus Ollama running for NLU. The integration adds Bhasa to Docker Compose so it can also run containerized.

> [!WARNING]
> **Your `.env` file contains real credentials** (MongoDB Atlas, Twilio, Deepgram, ElevenLabs, JWT secret). I will NOT modify those values but will add new Bhasa-specific env vars below the existing ones.

### Component 2: Upgrade STT Service — Bhasa Integration

#### [MODIFY] [app.js](file:///d:/Voice%20Agents/services/stt-service/src/app.js)

Add a Bhasa HTTP call path when `MOCK_MODE=false`:

```diff
 app.post('/transcribe', asyncHandler(async (req, res) => {
+  // When MOCK_MODE is off, proxy to Bhasa language service for real Whisper ASR
+  if (process.env.MOCK_MODE !== 'true') {
+    const languageUrl = process.env.LANGUAGE_SERVICE_URL || 'http://localhost:8003';
+    try {
+      const bhasa = await axios.post(`${languageUrl}/transcribe`, audioFormData, { headers });
+      return http.success(req, res, {
+        transcript: bhasa.data.text,
+        language: bhasa.data.language,
+        confidence: bhasa.data.confidence,
+        provider: 'bhasa-whisper'
+      }, 'Transcription completed');
+    } catch (err) {
+      logger.error('Bhasa ASR failed', { error: err.message });
+      // Fall through to mock if Bhasa is unreachable
+    }
+  }
+
   // Existing mock logic (unchanged)
   const transcript = req.body.text || ...;
```

- Supports both raw audio files (`multipart/form-data`) and text passthrough
- Falls back to mock if Bhasa is unreachable (graceful degradation)

### Component 3: Upgrade NLU Service — Bhasa Integration

#### [MODIFY] [app.js](file:///d:/Voice%20Agents/services/nlu-service/src/app.js)

Add a Bhasa NLU call when `MOCK_MODE=false`:

```diff
 app.post('/understand', asyncHandler(async (req, res) => {
+  if (process.env.MOCK_MODE !== 'true') {
+    const languageUrl = process.env.LANGUAGE_SERVICE_URL || 'http://localhost:8003';
+    try {
+      const bhasa = await axios.post(`${languageUrl}/understand`, {
+        text: transcript,
+        context: { history: req.body.history, entities: req.body.entities }
+      });
+      // Map Bhasa's response format to what call-gateway expects
+      return http.success(req, res, {
+        intent: bhasa.data.intent,
+        entities: mapBhasaEntities(bhasa.data.entities),
+        response: buildResponse(bhasa.data.intent, mapBhasaEntities(bhasa.data.entities)),
+        shouldEndCall: ...,
+        needsHuman: bhasa.data.intent === 'speak_to_human',
+        provider: 'bhasa-ollama'
+      }, 'Intent processed');
+    } catch (err) {
+      logger.warn('Bhasa NLU failed, falling back to rules', { error: err.message });
+    }
+  }
+
   // Existing rule-based logic (unchanged, acts as fallback)
```

- Bhasa returns intents in a slightly different format (snake_case like `book_ticket`) — we add a mapping layer to align with the main project's `constants.INTENTS`
- The existing rule-based `buildResponse()` is reused to generate the agent reply from AI-detected intents
- Graceful fallback to rule-based NLU

### Component 4: Upgrade TTS Service — Bhasa Integration

Add Bhasa TTS call when `MOCK_MODE=false`:

```diff
 app.post('/synthesize', asyncHandler(async (req, res) => {
+  if (process.env.MOCK_MODE !== 'true') {
+    const languageUrl = process.env.LANGUAGE_SERVICE_URL || 'http://localhost:8003';
+    try {
+      const bhasa = await axios.post(`${languageUrl}/speak`, {
+        text, language: req.body.language || 'hi', speed: 1.0
+      }, { responseType: 'arraybuffer' });

+      // Save audio to a temp file / serve URL
+      const audioUrl = await saveAudioAndGetUrl(bhasa.data);
+      return http.success(req, res, {
+        audioUrl,
+        text,
+        language: req.body.language || 'hi',
+        provider: 'bhasa-tts'
+      }, 'Speech synthesized');
+    } catch (err) {
+      logger.warn('Bhasa TTS failed', { error: err.message });
+    }
+  }
+
   // Existing mock logic (unchanged)
```

- Bhasa returns raw audio bytes (WAV/MP3) — we save to a local file and serve via a static URL, or base64 encode it for the response
- Add `express.static` for serving generated audio files
- Graceful fallback to mock
